csv,conf,v6 organizers

csv,conf is a group effort to put on a non-profit, community conference with dozens of people putting in time, including but not limited to the 2024 organizing team:

  • Karthik Ram, University of California, Berkeley. Program Chair
  • John Chodacki, California Digital Library
  • Elaine Wong, Canadian Broadcasting Corporation
  • Jessica Hardwicke, Code for Science & Society
  • Jonathan Cain, Columbia University Libraries
  • Jo Barratt, Open Knowledge Foundation
  • Danielle Robinson, Code for Science & Society
  • Lilly Winfree, Open Knowledge Foundation
  • Serah Rono, The Carpentries

We strive to be a supportive and welcoming environment to all attendees. We encourage you to read the Conf Code of Conduct and will be enforcing it.

You can revisit csv,conf,v7, csv,conf,v6, csv,conf,v5, csv,conf,v4, csv,conf,v3 , csv,conf,v2 and csv,conf,v1 conference websites, or watch csv,conf talks on YouTube.

The code for this website is open source. View it on GitHub.   Want to talk to us? Join us on Slack.
